🏊 Piscine Reloaded – 42
📌 Sobre o projeto

O Piscine Reloaded é um conjunto de exercícios de revisão da 42 School que serve como um reforço dos fundamentos da linguagem C.

Ele não introduz conceitos novos, mas revisa tudo o que foi visto na Piscine original, como:

Sintaxe básica da linguagem C
Ponteiros e memória
Funções
Estruturas de repetição
Manipulação de strings
Compilação com Makefile

O objetivo principal é relembrar e consolidar a base antes de entrar no Common Core.

🎯 Objetivo

Praticar e reforçar os conceitos essenciais de programação em C através de exercícios curtos e diretos, incluindo:

Funções básicas (ft_strlen, ft_strcmp, etc.)
Recursão e iteração
Ponteiros e arrays
Manipulação de arquivos
Uso de structs e headers
Criação de Makefiles
📁 Estrutura do projeto

O projeto é dividido em exercícios numerados:

ex00/
ex01/
ex02/
...
ex27/

Cada pasta contém:

Código fonte (.c)
Header (.h) quando necessário
Makefile (em alguns exercícios)
⚙️ Compilação

A maioria dos exercícios pode ser compilada com:

cc -Wall -Wextra -Werror *.c

Ou usando Makefile quando disponível:

make
🚀 Como executar

Após compilar:

./a.out

Ou o executável específico do exercício, por exemplo:

./ft_display_file arquivo.txt
